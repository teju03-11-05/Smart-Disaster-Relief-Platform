# Smart Disaster Relief Resource Coordination Platform

## Project Overview
The Smart Disaster Relief Resource Coordination Platform is designed to improve coordination during disasters such as floods, earthquakes, and cyclones.

The system helps manage emergency requests, rescue teams, relief resources, hospitals, shelters, and emergency response activities.

## Objectives
- Prioritize emergency requests
- Assign rescue teams
- Track relief resources
- Monitor rescue operations
- Improve disaster response coordination
- Generate response reports

## Features
- Emergency request submission
- Emergency severity selection
- Rescue team management
- Resource availability tracking
- Emergency response monitoring
